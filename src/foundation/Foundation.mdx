# Foundation

Foundation은 컴포넌트보다 먼저 결정되는 디자인 시스템의 기준입니다. 이 프로젝트에서는 색상, 타이포그래피, spacing을 먼저 문서화하고, 컴포넌트는 이 기준을 semantic token과 Tailwind class로 소비합니다.

## 구조

```txt
src/foundation
  color-palette
  typography
  spacing
```

## 원칙

- Foundation은 제품의 시각 언어를 정의합니다.
- Foundation 문서는 재사용 컴포넌트가 아닙니다.
- 컴포넌트는 foundation 값을 직접 복사하지 않고 semantic token을 통해 사용합니다.
- 색상 값은 `src/tokens/color-tokens.json`을 SSOT로 사용합니다.
- Typography와 Spacing은 현재 Tailwind scale을 기준으로 문서화합니다.

## Token flow

```txt
primitive token -> semantic token -> styled component
```

예시:

```txt
primitive.green.600
  -> primary.solid
  -> bg-primary-solid
```

## 문서 페이지

- `Color Palette`: primitive color와 semantic color alias
- `Typography`: type scale, font weight, line-height, semantic content color
- `Spacing`: Tailwind 4px spacing scale

## 컴포넌트와의 관계

Foundation은 컴포넌트보다 상위 레이어입니다. 예를 들어 `Button`은 green hex 값을 직접 알지 않고 `bg-primary-solid` 같은 semantic class만 사용합니다. 이렇게 하면 palette가 바뀌어도 컴포넌트 구현을 직접 수정하지 않아도 됩니다.
