# IconButton

아이콘만으로 명령을 실행합니다.

    - 넘긴 아이콘은 장식으로 남습니다. 아이콘에 `title`을 함께 주면 이름이 두 번 읽힙니다.
    - 뜻이 분명하지 않은 동작에는 아이콘만 두지 말고 텍스트가 있는 Button을 사용합니다.
