# Icons

24×24 그리드 위에 stroke로 그린 아이콘 세트입니다.

<DocsTabs>
  <DocsTab value="overview">
    <Canvas of={IconsStories.All} />

    - 색은 `currentColor`를 따르므로 색상 prop 없이 주변 텍스트 색을 그대로 씁니다.
    - 옆에 같은 뜻의 텍스트가 있으면 장식이므로 이름을 주지 않습니다. 기본값이 `aria-hidden`입니다.
    - 아이콘만 단독으로 의미를 전달할 때만 `title`을 넘겨 `role="img"`와 이름을 갖게 합니다.
    - 크기는 `size`(px)로 정하고, Tailwind `size-*` 클래스로 덮어쓸 수 있습니다.
    - 새 아이콘은 `createIcon`으로 만들어야 크기, 색, 접근성 처리가 같아집니다.
